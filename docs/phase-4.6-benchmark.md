# Phase 4.6 수집 전 전략 비교

2026-09-21. Phase4.5 실제 UC 요청1회에서113명·선택한7강화791가격을 확보했다. 응답은 +1~13 가격과 0강 '-' 칸을 포함했다. 이번 재조사에서도 UI 0~13 선택지를 확인했고, OVR0~1 빈 검색 요청은 HTTP200 / 871ms로 공식 빈 결과 마크업을 반환했다. 강화별 가격은 추정하지 않는다.

A/B는 부하를 만들지 않은 분석 추정이며 실제로 전체 실행한 측정치가 아니다. C 모델은 클래스별 ceil(metadata/150) leaf가 필요하다고 가정하고 2L-1 이진 트리 요청을 계산한다. 보장이 아니며 metadata가 현재 등재 수와 다를 수 있다. 모든 OVR 정수0~200까지 분할할 경우 클래스당 최대401노드,153클래스61,353노드이며 그 상태에서도 단일OVR200명 한계가 남는다. 페이지2나 미검증 분할 필터로 우회하지 않는다.

C를 선택한다. 88,359×13=1,148,667은 현재 유효 조합 수가 아니라 가격 조합의 metadata 상한이다. 0강은 표시 확인 대상이지만 검증 fixture에서는 가격 미표시이며 가격 variant를 생성하지 않는다. 실제 유효 가격 조합 수는 수집 후 계산한다.

전체 요청을 즉시 실행하기에는 분포/시간/사이트 제약이 불확실하므로 첫20구간 배치와 resume 배치로 확인한다. 전체 run의153클래스 계획을 유지하고 미처리 구간을 숨기지 않는다. 사용자 명세56항의 제한 배치 실행 경로를 따른다. 429/보안 제한은 우회하지 않고 중단한다. 개별5xx/timeout은 제한된 재시도와 지연 증가 후 다른 구간으로 진행한다.
