# Phase 1 데이터 확인 기록

조사일: 2026-09-18 (KST). 자동 수집기나 외부 계정 연결은 구현하지 않았습니다.

## 다시 확인한 공식 출처

- https://shop.fconline.nexon.com/
  - 일반 상품, FC 구매, 마일리지, 스페셜 상점과 공식 확률 링크 확인.
  - 공개 추출 결과에서 상품별 가격·구성·판매 기간·구매 제한을 한 상품에 대해 충분히 검증하지 못함.
- https://iteminfo.nexon.com/probability/fco
  - 아이템별 확률 공시 목록 확인.
  - 아이템 공시의 판매/획득 가능 기간만으로 상점 상품의 가격·판매 기간·구매 제한을 단정하지 않음.

## 결론

Official 상품 seed: **0종**. 공식 데이터 연동 상태: **NEEDS_VERIFICATION**.

FC Detox 정보는 seed에 사용하지 않았습니다. 공식 상품의 일부 값을 추측하여 완성하지 않았습니다.

## 개발용 데이터

위치: `src/data/mock/catalog.ts`.

- 파운데이션 패키지: 수량과 중첩 구성 테스트.
- 디스커버리 박스: 상자 하위 구조 테스트.
- 데이터 확인용 패키지: 가격·구성 미확보 상태 테스트.

모든 상품·아이템·가격은 자체 작성한 예시입니다. `MOCK` 출처와 `MOCK` 데이터 유형을 저장합니다. 공식 검증 시각은 null이며 수정 시각과 구분합니다. 공식 검증 완료로 승격할 수 없습니다. 이미지도 자체 SVG이며 넥슨/EA/FC Detox 에셋을 가져오지 않았습니다.

## 향후 공식 상품 등록 조건

상품 식별, 가격과 통화, 구성품 수량, 판매 기간·구매 제한 각각의 근거를 기록해야 합니다. 모르는 필드는 null을 유지합니다. `VERIFIED`는 공식 출처 URL과 확인 시각이 있어야 합니다. 데이터 구조를 통과했다는 것과 내용이 공식 사실로 검증됐다는 것은 다릅니다.

공식 상품 버전을 등록할 때 개발용 데이터셋과 분리하고 모든 구성품 참조 및 검증 상태를 확인합니다. 서로 다른 데이터셋을 가로지르는 구성품 참조는 Phase 1에서 지원하지 않습니다.
