## 확률 출처와 접근 한계

[공식 확률 안내](https://iteminfo.nexon.com/probability/fco)의 직접 브라우저 및 일반 HTTP 요청은 보안 확인 화면에 막혔다. 우회하지 않았으며, 공개 웹 조회 도구가 제공한 **공식 페이지 본문**을 수집했다. 확률 스냅샷의 수집 방식은 `PUBLIC_WEB_TEXT`다. 조회 결과의 캐시 표시는 당일부터 지난주까지 달랐고 각 스냅샷의 retrievalNote에 기록했다.

따라서 fetchedAt은 본문을 수집한 시각, verifiedAt은 저장된 정의를 확인한 시각이다. 원 서버의 최종 갱신 시각이나 실시간 최신성을 보증하지 않는다. VERIFIED는 해당 공식 스냅샷의 정의·관계·수치 검증을 의미한다. 판매 상품 페이지는 별도로 실제 브라우저에서 확인했다.

`src/data/official/product-44699/snapshots.json`에는 민감한 페이지 토큰을 제외한 추출 본문 14개가 있다. SHA-256은 이 **저장 본문**의 해시이며 원본 HTTP 바이트의 해시라고 주장하지 않는다. 상품 상세·목록 2개와 확률표 12개를 보관한다. 테스트용 합성 반올림 표는 `tests/fixtures/official/`에 별도로 둔다.

메인 상자 원문 확률은 순서대로 `0.3725000000000000%`, `0.3725000000000000%`, `1.1272000000000000%`, `24.2770000000000000%`, `73.8508000000000000%`다. ALL 표의 두 행은 각각 100%이므로 합계 200%가 정상이다.

선수팩 6개는 총 1,195개의 기준가 순위 보상이다. TOP 1부터 각 표의 마지막 순위까지 누락 없이 저장했다. 선수 이름으로 치환하지 않았다. 클래스, 강화, OVR, 생성 제한, 개봉일 0~1시 기준가 조건을 원문으로 보존했다. 확률 적용 기간의 점검 전·후 표현은 상품 판매 기간의 08:00과 별개로 보존한다.

코인의 교환 안내 및 사용 기한 원문은 저장하지만 교환 규칙이나 보상 지급은 구현하지 않는다. 이 아이템의 rewardBehavior는 UNKNOWN이다. 공개된 보상 정의를 확인했다는 사실과 향후 실제 선수·이벤트 교환 보상까지 확정했다는 주장은 구분한다.

## 참고 사이트

[FC Detox](https://fcdetox.com/)와 해당 상품 화면을 읽고 중첩 구성품 및 확률 진입 UX를 참고했다. 해당 사이트의 구성 요약이나 계산값을 공식 데이터로 복사하지 않았다. 개봉 기능은 실행하지 않았다.
